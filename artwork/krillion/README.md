# Krillion artwork

Deze map bevat de nieuwe Krillion/zeeschildpad als visuele referentie.

## Technische specificatie

- Huidige bron: `krillion-current-reference.png`
- Origineel artwork: 1536×1024 px PNG
- Aanbevolen gameformaat: 64×64 px pixel-art
- Voor extra scherpte mag je werken op 128×128 px en daarna terugschalen naar 64×64 px
- De nieuwe PNG heeft een transparante RGBA-achtergrond en is geschikt als bronbestand
- Harde pixelranden; geen anti-aliasing
- Houd het karakter ongeveer binnen het bestaande 64×64 kader
- Lever bij voorkeur SVG of PNG aan

De game schaalt het karakter tijdens het spelen op naar ongeveer 64 px. Tijdens speciale momenten kan het groter worden, tot ongeveer 88 px op desktop en 66 px op mobiel.

Als je een nieuwe versie maakt, vervang dan niet zelf het bronbestand. Zet je nieuwe bestand naast deze referentie met bijvoorbeeld de naam `krillion-new.svg` of `krillion-new.png`; dan kan het veilig worden getest en aangesloten.
